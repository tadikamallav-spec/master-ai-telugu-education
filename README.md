## MOST IMPORTANT: How to add links
For normal updates, edit only **site-data.js**.

Find the relevant section:
- `aiTools` — AI tools
- `practice` — HTML practice links
- `videos` — YouTube/video links
- `prompts` — ready prompts
- `app` — Learning App links
- `resources` — PDFs/Drive/Forms/resources
- `social` — YouTube/Instagram/Facebook/WhatsApp

Replace `#` with your public link.

Example:
```js
{name:"Hindi Grammar Test", icon:"अ", desc:"Class 10 practice", url:"https://YOUR-LINK-HERE", tags:["Hindi","HTML"]}
```

## Add a new item
Copy one existing `{ ... }` item, paste it below it, change the title/description/url.

## GitHub Pages
After uploading all files:
1. Open repository **Settings**
2. Open **Pages**
3. Under Build and deployment choose **Deploy from a branch**
4. Branch: **main**
5. Folder: **/(root)**
6. Save

GitHub will then provide the public website URL.

## Files
- `index.html` — website structure
- `styles.css` — design
- `script.js` — functionality/search/cards
- `site-data.js` — **easy-edit content and links**
- `manifest.json` — app-like metadata

No paid API or database is required for this V1.
